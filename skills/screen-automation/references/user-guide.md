# 从自然语言任务到桌面流程

Skill 或专家安装在 AI 助手的运行环境中，
自动化流程安装在小助手桌面端中；两者安装位置和用途不同。

本指引帮助 Agent 向用户解释如何开始、如何反复运行，以及遇到问题时怎样继续。
具体命令使用 [流程开发标准](workflow-standard.md) 和当前 CLI，不要求用户手工编写命令或流程代码。

## 1. 第一次怎样使用

用户安装 Skill 或专家，并在同一台电脑安装、启动屏幕自动化小助手桌面端后，在具备本机工具调用能力的
AI 助手中直接描述目标，例如“帮我读取左边窗口”“复制这篇文章正文”。Agent 检查连接并确认目标窗口，
再观察、操作和验证。若当前环境不能调用本机工具，应说明需要的运行环境，不能声称已经读取或操作屏幕。

用户无需先了解 OCR、DOM、坐标或流程语言。只读任务先读取；需要操作时按任务范围推进。
账号登录、授权、凭据输入、支付及其他高风险操作，按 Skill 主入口要求暂停并交给用户在场完成。

任务只做一次就直接完成。经常重复时，可以说：

> 把刚才验证过的操作做成自动化流程，下次在小助手桌面端直接运行。

Agent 将关键步骤、输入参数、完成标志与失败处理写清楚，让用户审阅，而不是让用户重复解释技术细节。
确定性流程不需要配置“Agent接入”；流程需要智能定位、执行或异常判断时，再说明用途并引导配置。

## 2. 流程生成后怎样使用

1. **审阅和试运行**：Agent 展示自然语言步骤、参数、输出、所需组件及人工交接点，先校验本地包，
   再用一条安全数据试运行。未完成的测试和依赖明确标出，不能将“生成了文件”说成“已验证可用”。
2. **将流程安装到小助手桌面端**：按用户创建并使用流程的请求，由 Agent 使用小助手桌面端的流程安装入口完成安装，
   再校验已安装副本。交付时说明实际流程名称、标识和版本。若当前没有安装条件，交付流程包的具体位置，
   按小助手桌面端实际提供的流程安装入口指导，不编造菜单或按钮。
3. **以后直接运行**：打开小助手桌面端，在流程列表找到该流程，检查参数并运行。基础流程不需要保持与
   平台 Agent 的对话；含智能能力的流程仍需要已配置的 Agent 接入及对应服务可用。
   目标应用、账号登录和必要组件等运行前提也应满足。
4. **查看结果**：先查看运行状态，再按该流程的说明查看结果文件、保存位置或目标应用中的业务结果。
   Agent 必须给出本次实际输出位置；没有生成文件就说明结果在哪里，不能虚构路径，或把日志当成交付结果。
   如需进一步整理，可以回到对话说“帮我读取这次流程的结果”。
5. **修改流程**：向 Agent 说明流程名称、想改的目标或失败位置。Agent 读取现有流程，在草稿中修改、
   校验、试运行并安装，再告知变化。用户不用自己修改 Python、坐标或命令。

首次真实运行由用户监督，确认操作对象和业务结果。账号授权、支付等人工步骤不能因为“以后直接运行”
而自动化代办；流程到相应位置要等待用户完成并验证。普通运行也应提供清晰的停止方法。

## 3. 失败、等待或停止时怎么办

- **等待选窗口**：确认提示中的目标窗口；无法唯一确认时让用户选择。不要随便选同名窗口，也不从头重跑。
- **等待登录、授权或高风险操作**：保留当前页面，用户在场完成。桌面流程处于等待状态时，按界面提示点击
  “继续”；对话中的单次任务则告诉 Agent“已完成”。两种情况下都需重新观察验证，才继续后续操作。
- **目标没找到、页面变了或结果不符合预期**：Agent 先检查本次现场，按流程已声明的有界路线恢复。
  需要用户处理时说明“停在哪一步、看到了什么、需要做什么”。用户可以调整页面后继续；不要反复点击“运行”
  造成重复发送、保存或提交。能否原地继续以实际运行状态为准，已失败退出的任务先核对已有结果再决定重跑。
- **组件或 Agent 未就绪**：说明具体缺少的组件、授权或连接，引导用户在相应设置中完成后重新检查。
  基础能力能完成的部分继续使用，不将所有问题都归为需要配置 Agent。
- **想暂停或停止**：使用当前任务或桌面运行的暂停、停止入口。停止可能先进入收尾，核对状态后再报告实际结束。
  不把“停止请求已发送”当成已经退出，也不默认关闭用户窗口。

请用户提供流程名称、出错步骤、预期结果、实际现象和必要的脱敏错误信息；不要索取密码、验证码、Cookie
或整屏敏感截图。Agent 的说明应区分已完成、未完成、保存下来的结果，以及下一步建议。

详细失败路线与继续条件见 [阶段契约](workflow-agent-phases.md)，收尾和停止状态见
[流程生命周期](workflow-lifecycle.md)。

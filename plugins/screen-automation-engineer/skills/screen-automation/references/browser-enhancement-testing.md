# 浏览器增强测试标准

本标准用于验证小助手的浏览器增强能力及使用它的流程。测试只操作小助手创建的独立受管 Profile；不得拿
用户日常 Chrome/Edge Profile、真实账号或敏感页面充当通用测试环境。所有写操作先在本地或专用测试页完成。

## 测试前记录

记录桌面端版本、操作系统与架构、浏览器及版本、组件版本、测试页、测试时间和实际命令。先执行：

```text
cli status
cli capabilities
cli access list
```

只有 `cli capabilities` 列出 `workflow.browser-enhancement@1`，且 `cli access list` 中
`browser_enhancement.status.effective` 为 `true`，才进入真实操作。输出中能力码、凭证、个人路径和页面
隐私必须脱敏；不得为了测试索取、记录、代输或绕过能力码。

## 分层用例

| 层级 | 必测用例 | 通过标准 |
| --- | --- | --- |
| 动作契约 | 检查 `workflow.browser-enhancement@1` 与 `ctx.browser` 方法 | 当前版本明确声明；不能仅凭文档猜测 |
| 访问状态 | 已授权已安装、未授权、未安装、未启用、平台不支持 | 分别报告 `effective`、`reason`、`action`，不混成同一种故障 |
| 目标窗口推荐 | 绑定 Chrome/Edge、非浏览器、能力无效、用户拒绝、用户确认已关闭 | 只在支持且有效时简短推荐；不自动关窗；拒绝后保留普通屏幕路径 |
| 当前页面交接 | 合法 http/https URL、空地址、新标签页、浏览器内部页、原剪贴板恢复 | 关闭提示前取得合法 URL；原剪贴板恢复；URL 不进日志；失败时不让用户先关窗 |
| 内容选择 | 单元素、跨滚动长元素、零/多匹配、隐藏元素、过期/跨会话对象、iframe | 选区属于唯一可见目标；只记录字符数；失败不退化为坐标拖拽 |
| 内容复制 | `text`/`value`/`href`、空内容、1 MiB 边界与超限、剪贴板拒绝、敏感日志检查 | 经读取与剪贴板权限写入；正文不进日志；超限停止且不截断 |
| 流程静态校验 | 缺引擎能力、缺读取/操作/下载/会话权限、改变页面却无验证 | 非法流程被拒绝并指出具体缺项 |
| 会话 | Chrome；Windows 再测 Edge；重复打开；关闭后复用对象 | 独立受管 Profile；重复打开和跨会话对象被拒绝；结束后进程清理 |
| 定位与读取 | 唯一、零匹配、多匹配、含文字过滤、隐藏元素、滚动后元素 | 只返回当前会话可见对象；零个或多个匹配安全停止 |
| 页面操作 | 导航、点击、填写、滚动、按键 | 每项有操作前状态与操作后重新定位/读取或屏幕证据 |
| 下载 | 合法文件名、路径穿越文件名、取消/超时 | 只写入本次运行的 `browser_downloads`；不能指定任意目录 |
| 屏幕交叉验证 | DOM 动作成功但可见页面未变化；颜色或文字验证失败 | 不把协议成功当成业务成功；进入有界恢复或停止 |
| 停止与故障 | 挂起导航时停止、浏览器被关闭、Sidecar 退出、组件版本/协议不匹配 | 停止可及时中断；故障可解释且不退化为猜坐标或普通 Profile |
| 生命周期 | 检查更新、回退、卸载、重装 | 签名和版本受校验；卸载组件保留受管 Profile；普通 Profile 不受影响 |

## 推荐测试页

使用本地静态页覆盖：标题和正文读取、两个同 selector 元素、隐藏元素、视口外元素、输入框、改变可见状态的
按钮、横纵滚动区和 data URL 下载。另准备一个故意不响应的本地 HTTP 端点验证停止和超时。测试页不得依赖
第三方网站的实时结构；真实业务页面只用于最后一轮用户监督验收。

## 结果分级

- `静态通过`：仅语法、权限、协议和单元测试通过。
- `本机 Sidecar 通过`：真实 Chrome/Edge 受管窗口完成定位、读取、操作、下载、验证和停止。
- `正式组件通过`：从正式清单下载、验签、隔离安装、运行、更新、卸载和重装通过。
- `业务页面通过`：由用户授权并监督，在指定真实页面完成一条安全数据。

报告必须列出每一层的通过、失败和跳过项。未执行正式下载或真实业务页面时，不得写“浏览器增强完整验收通过”。
